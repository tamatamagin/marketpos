# 市集開單（網頁版）

擺市集用嘅開單／埋數網頁 App。一個 HTML 檔，離線用得，唔需要帳號、唔需要上網、唔需要裝 app。
電話（Android／iPhone）同電腦都用得。

## 三個分頁

### ① 開單（招呼客人）
- 兩欄貨品格，大圖＋名＋價錢＋剩幾件
- **撳一下張相就加一件**，卡片右上角顯示今單揀咗幾件（×2）
- 頂部一直顯示「今日 $677 · 4 單」
- 底部固定 bar「N 件 / $XXX」，撳「埋單」彈出今單：
  - 每行 −／＋ 改數量，減到 0 自動走
  - **大字總數**，客人直接睇
  - 揀付款方式（現金／PayMe／轉數快／其他）
  - 「確認收款」→ 出「已收款」畫面 → 「繼續開單」
- 唔夠貨擋住唔俾加，賣晒嘅貨會蓋「賣晒」

### ② 產品（事前設定）
- 「＋ 新貨品」：**相片（相簿或即場影，自動壓到 760px／約 4–90KB）＋名＋價錢＋數量**
- 可以剔「不限數量」（訂製、可再鈎）
- 撳一行改任何嘢；右邊 icon：
  - 🔄 重設剩貨（補貨但唔想改數字時用）
  - 📦 收起（今次唔賣，保留歷史）
  - 🗑 刪除（過去單據仍然保留）
- 改「數量」會自動由嗰刻起重新計剩貨 → 下次市集入貨唔會夾埋上次啲單
- 頂 bar：💾 資料備份（下載／還原 JSON）、🏪 改檔口名

### ③ 埋數（收檔用）
- 日期前後跳（只到今日），有單嘅日子都查得
- **總收入大字**＋單數／件數／平均單
- 付款方式分佈、貨品銷量（按件數排）、收檔剩貨（剩／總）
- 當日單據列表，逐張可刪（取消單／退款），埋數即刻更新
- 右上 ↗ 分享：手機直接開分享面板（WhatsApp／電郵），電腦自動複製文字

## 點用

**最簡單**：直接開 `市集開單.html`（雙擊就得，唔需要上網）。
> 注意：用 `file://` 開嘅話，資料綁死喺嗰個位置。想穩定啲就用下面方法。

**建議（電話加主畫面，似 app 咁用）**：把 `index.html`、`manifest.webmanifest`、`sw.js`、`icon-*.png` 放上任何靜態網頁空間（GitHub Pages／Netlify／自己 server 都得），用電話開，然後：
- Android Chrome：⋮ → 「安裝應用程式」／「加到主屏幕」
- iPhone Safari：分享 → 「加入主畫面」

裝完之後**離線都用得**（有 service worker 快取）。

## 資料同安全
- 存喺瀏覽器 `localStorage`（key `marketpos.v1`），大約 5MB 上限
- 相片自動壓縮：一張普通相約 4–90KB，一般夠擺 50+ 件貨
- 冇網絡請求、冇追蹤、冇廣告；所有計算都喺部機做
- 💾 備份：下載 JSON 存去 Google Drive／電郵；換電話就「還原」返
- **清瀏覽器資料會冇晒**，所以收檔後最好下載一次備份

## 檔案
```
index.html            主程式（單檔，全部 CSS/JS 內嵌）
manifest.webmanifest  PWA 設定（名、色、icon）
sw.js                 service worker（離線快取）
icon-192.png          主畫面圖示
icon-512.png
```

## 已知限制
- 單機、冇多部電話同步（要同步可以加 Firebase／自架 server）
- 冇藍牙單據打印（用分享文字代替）
- 冇稅／折扣／找續計算機
- localStorage 5MB 上限：相片太多就要刪舊單或改用 IndexedDB
